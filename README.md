# AI 竞调采集器

面向 AI 短剧内容生产平台的竞品调研采集工具。它将统一截图、人工标注、竞调素材库与飞书多维表格沉淀串联起来。

## 包含内容

- 通用截图与批量流程走查脚本
- 竞调截图入库、标注及索引生成
- 本地悬浮工作台的 SwiftUI 源码
- 飞书同步适配逻辑与安全的本地配置约定

## 使用前准备

本仓库不含登录态、截图、任务记录、飞书路由配置或已编译应用。首次使用时需：

1. 安装 Node.js、Playwright 和本机浏览器。
2. 配置自己的飞书应用及授权。
3. 在 `截图文件/`、`浏览器资料/` 下生成自己的本地数据。
4. 使用 `内部程序文件/原生悬浮工作台.swift` 编译本地 App，或使用顶层 `.command` 脚本启动工具。

详细操作请查看 [使用说明.md](使用说明.md)。
